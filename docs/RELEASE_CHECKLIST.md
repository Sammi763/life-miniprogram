## 2. 生产基础设施

- [ ] 从 `server/.env.production.example` 创建仅服务器可读的 `.env`，设置 `DEV_MODE=0`、`BIND_HOST=127.0.0.1`、`REQUIRE_HTTPS=1`、`HEALTH_DETAILS=0`。
- [ ] 配置正式 `WX_APPID`、`WX_SECRET`、订阅模板 ID、独立随机 `AI_SECRET_ENCRYPTION_KEY`、数据库密码；这些值不得进入 Git、日志、截图或客服消息。
- [ ] 使用 [Caddyfile.example](../server/deploy/Caddyfile.example) 配置 HTTPS，先验证证书、`/api/health`、`/api/*` 和 `/ws`；Node 的 8787 端口只允许本机反代访问。
- [ ] 在微信后台配置 request/socket 合法域名 `https://wx.yzflab.top` 和 `wss://wx.yzflab.top` 以及业务域名（如后续实际使用）；不配置 IP 和本地地址。
- [ ] 使用 [mysql-production-init.sql.example](../server/deploy/mysql-production-init.sql.example) 创建低权限运行账号。由独立迁移账号执行 `npm run db:migrate`，生产服务保持 `DB_AUTO_CREATE=0` 和 `DB_RUN_MIGRATIONS=0`。
- [ ] 安装并启用 `life-sync.service`、`life-backup.service`、`life-backup.timer`；确认 `systemctl status` 和 `systemctl list-timers` 正常。
- [ ] **部署顺序**：凡改动记录字段白名单（`miniprogram/utils/record-validation.js`，server 侧经 `server/validation.js` re-export）的小程序版本，必须先部署 server、再上传对应小程序版本；顺序颠倒会造成旧服务端 422、写入进「待同步-被拒」（2026-09-24 aiConsent 事故）。
- [ ] **打包与共享工具**：服务端部署物必须用 `RELEASE_VERSION=<版本> node server/scripts/pack-release.js` 现打（含 `server/**` 与共享的 `miniprogram/utils/**` 及 manifest）；仓库根目录的 `life-sync-*.tar.gz` 是历史归档，**不得充当新版包**。上传前核对 `.manifest.json` 的文件数与 `miniprogram/utils/record-validation.js` 的 sha256。
- [ ] **启动前模块加载检查**：新版共享工具先就位（解包 + `npm ci --omit=dev`），再在解包目录执行 `node server/scripts/check-runtime-modules.js <解包>/server`（全部模块 require 通过），**然后**启动新版 server，**最后**上传小程序版本。任何 `Cannot find module` 都必须先修复再启动。

## 5. 自动检查与真机验收

- [ ] CI `Verify life miniprogram` 通过：语法检查、全量测试、依赖审计和源代码密钥扫描。
- [ ] 本地运行 `npm run security:scan --prefix server` 与 `npm run release:check --prefix server`；后者必须通过才允许上传正式版。
- [ ] 同一部手机使用 5G 完整验收：微信登录、跳过昵称、进入首页、保存一条记录、退出并重新进入后仍能读到该记录；以实际 `POST /api/login` 与数据读写结果为准。
- [ ] 在第二个微信账号下确认看不到第一个账号的记录；第一个账号再次登录仍能读取原记录。
- [ ] 真机 HTTPS 登录、编辑昵称、退出/重新登录、账户导出和账户删除。
- [ ] 登录重试验收：连接重置/被拒绝/超时后重新取 code 并重试，最多 5 次尝试、退避约 8.2 秒；连续传输失败后加载态结束且可再次点击；HTTP 401 只请求一次；失败态可点「网络自检」并得到明确结论（服务端可达 / 不可达）。
- [ ] 主包体积验收：微信开发者工具「详情 → 本地代码」确认主包体积在合理范围（本版 logo 已由 887KB 压缩至 137KB）；不要再引入超过 200KB 的单张静态图。
- [ ] 交互反馈验收：断网后点离线横幅「重试」，应先出现加载态、结束后给出「已同步」或「仍无法连接」提示；快速双击「保存」不产生两条相同记录；双击勾选不会把打卡抵消；小屏手机上打开字段最多的记账账户弹层，保存按钮可滚动到。
- [ ] 本机缓存验收：「我的 → 数据状态」显示的本机缓存占用与实际相符；模拟写入失败（可临时把单 key 上限压到很小）时页面出现红色提示且「重建本机缓存」可用；重建后未上送的队列条数不减少，联网后记录完整回来。
- [ ] 异常留痕验收：制造一次 JS 异常，确认「我的」页出现异常提示、且提示文本中不含完整令牌（`token=***`）；确认没有任何崩溃上报请求发出（可抓包核对只访问自有域名）。
- [ ] 分享验收：在「我的」页点「转发给微信好友」，卡片标题必须是固定中性文案、分享图为应用 logo，**不得出现账本金额、随记正文等任何个人数据**；逐页用右上角菜单确认转发可用；「今日/记账/习惯/我的」等 tab 页分享到朋友圈后进入的是「单页模式」（无登录态、不渲染 tabBar），需真机确认观感，若不理想再决定是否收窄朋友圈入口。
- [ ] 时间线分批验收：写入 200 条以上随记后打开「生活时间线」，首屏只渲染最近 60 条且底部出现「已显示最近 60 条，共 N 条」与「加载更早的随记」；点一次累加到 120 条（不是替换）；顶部「N 条记忆 · M 个日子」始终是完整统计；切换关键词/心情/标签筛选后回到第一批。
- [ ] 悬浮导航留白验收：在「今日/记账/习惯/我的」四页分别滚到最底，确认最后一张卡片完整可见、未被悬浮 tabBar 压住；带底部安全区的机型（如 iPhone 12/13，安全区 34px）必须与不带安全区的机型各验一台。`.tabbar-spacer` 必须写成 `calc(Nrpx + env(safe-area-inset-bottom))` 且 N ≥ 悬浮胶囊 112rpx + 下边距 16rpx + 16rpx 呼吸位（见 `tests/layout-guards.test.js`）。
- [ ] 习惯卡片可点区域验收：习惯页每张卡片右上角的「+1 / 打卡」胶囊与右下角「管理」不得有任何重叠；点胶囊任意位置都必须只触发打卡，不得误入编辑弹层。
- [ ] 月度报告趋势验收：报告页「每日支出趋势」左侧日期必须是单行「23日」，不得被挤成「23 / 日」两行。
- [ ] 弹层可提交验收（**必做**）：在「记账」页点「＋」打开「记一笔」，确认「保存」按钮完整可见、可直接点中并成功创建记录；再在「习惯」页打开新增弹层做同样确认。悬浮导航在弹层打开期间必须整体隐藏、关闭后恢复。自定义 tabBar 与页面内容不在同一层叠上下文，页面内任何 `z-index` 都盖不住它（实测 `.sheet` 提到 200 仍被 `.tabbar-shell` 压住），所以只能靠 `hidden` 隐藏（见 `tests/layout-guards.test.js`）。
- [ ] 金额显示口径验收：同屏不得出现两种写法。约定为「整数不带小数、有小数最多两位且去末尾 0」（`¥89` / `¥54.5` / `¥143.5`），唯一实现是 `miniprogram/utils/finance.js` 的 `formatMoney`（见 `tests/money-format.test.js`）。记账、待买、月度报告三页各抽一条带小数的数据核对。
- [ ] 写入被拒验收：把服务端校验临时改成拒绝某条写入，确认客户端**不会**每 15 秒重发（旧实现会无限重试并永久堵住整个写队列），而是在「我的 → 数据状态」显示「N 条改动被云端拒绝」+ 具体 `collection/id · HTTP xxx`，且「重试」按钮可手动重发；恢复服务端后点重试应能成功（见 `tests/sync-rejection.test.js`）。
- [ ] 严格模式编译验收：改完任意 `miniprogram/**/*.js` 后必须重新编译并在模拟器打开受影响页面。`node --check` 与单元测试都**检测不到**「同文件重复顶层声明」（严格模式下是语法错误，会导致整个模块不被注入、页面白屏），需由 `tests/strict-syntax.test.js` 兜住。
- [ ] 点击反馈验收：全部可点元素（`view` / `button`）都带 `hover-class` 且显式声明 `hover-start-time` / `hover-stay-time`；`text` 组件不支持 `hover-class`，文件里剩余的 6 处可点 `text` 是白名单（落在 `> text:nth-child` 类型选择器或行内文本流里，换标签会改坏布局）。按压过渡一律 ≤ 100ms，不得退回微信默认的 `hover-stay-time: 400ms`（见 `tests/tap-feedback.test.js`）。真机上逐页确认点下去立刻有可见反馈。
- [ ] 编译噪音验收：开发者工具「详情 → 本地设置」的**「启用数据预拉取」必须保持关闭**（`project.private.config.json` 的 `preloadBackgroundData: false`）。开着但项目没有 `preloadRule` / 预拉取下载地址时，每次编译都会弹 `系统错误，错误码：6000100,unbind download url` 模态框，**模态框会盖住模拟器、直接吞掉点击**。本项目全仓没有任何预拉取 API 调用，必须保持关闭；不得在 `app.json` 里引入 `preloadRule`。
- [ ] 点击跟手性验收（真机）：Tab 切换、列表卡片、筛选 chip、弹层按钮各点 3 次，确认按压态随手指出现与消失、松手后不残留。模拟器实测 `switchTab` 从发起到 complete 约 222ms（其中业务代码只占约 16ms，其余是框架与模拟器开销），**模拟器手感不能作为验收依据，必须在真机上确认**。
- [ ] 设置信息架构验收：在「我的」页滚到底，确认「数据与隐私」一级只有 **3 行**（个性化 AI 文案开关 / 隐私与合规 / 数据管理），且「永久删除账户与数据」「退出当前账号」位于**独立的「账号」卡**内、不与普通设置同卡——不可逆操作必须隔离，这是隐私类应用的安全不变量（见 `tests/mine-settings.test.js`）。点「隐私与合规」应进入 `pages/legal/legal` 并能切换隐私政策 / 服务协议 / 第三方说明三个 tab；点「数据管理」应弹出底部弹层且悬浮导航同时隐藏，四个动作（导出云端备份 / 复制本机备份 / 重建本机缓存 / 清理示例内容）执行后弹层必须自动收起。
- [ ] 新建未来一次性定时日程，验证订阅同意、到点跳转；拒绝订阅时日程仍保存。
- [ ] 断网新增记录后恢复网络，确认队列只同步一次；再验证历史月报、随记搜索和时间线。
- [ ] 若登录重试仍失败，按时间核对小程序错误类别/耗时/服务端失败阶段、Nginx 访问日志和服务端 `event=login` 记录。有 HTTP 记录时按状态码定位；没有 HTTP 记录时结合 TCP 抓包定位连接重置发生端。不得从日志记录或截图中收集 code、令牌、手机号或密钥。
