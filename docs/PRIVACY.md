# 生活记忆 life · 微信小程序隐私保护指引配置稿

这是提交微信后台「服务内容声明 / 用户隐私保护指引」时的配置依据。只声明当前版本实际调用的能力；运营者名称、联系信息和第三方主体仍须在发布前按实际情况补全。

| 信息/能力 | 触发方式 | 使用目的 | 处理范围与去向 |
|---|---|---|---|
| 微信登录凭证、微信返回的用户唯一标识 | 用户点击「微信登录并开始」后 | 创建登录态、隔离每个用户的数据 | 登录凭证发送至本项目自建服务端，再由服务端与微信接口校验；用户唯一标识仅存于自建数据库 |
| 微信昵称 | 用户主动填写昵称后 | 展示文字个人标识 | 保存到自建服务端；可随时修改 |
| 手机号授权 code 与掩码手机号 | 用户主动点击「授权手机号」且同意微信隐私指引后 | 账号保护 | 授权 code 仅由自建服务端向微信官方接口交换；完整号码不落库，仅保存掩码（如 `138****0000`） |
| 生活记录 | 用户主动保存记账、账户、日程、习惯、体重、书影音或纯文字随记后 | 同步、时间线、周/月复盘、本机统计与 JSON 导出 | 保存到自建服务端；不会公开展示，也不会用于广告画像 |
| 剪贴板 | 用户主动点击「导出云端备份」或「复制本机备份」后 | 把用户选择的 JSON 副本交给用户自行保存 | 内容仅写入当前设备系统剪贴板，不上传第三方 |
| 个性化 AI 文案（可选） | 用户在「我的 → 数据与隐私」主动开启后 | 生成今日轻提醒和月度一句话 | 服务端才会向 DeepSeek API 发送裁剪后的部分随记正文、任务标题、心情/标签和汇总统计；不发送手机号、登录凭证、账户余额、原始账本备注或完整同步库 |
| 本机缓存、服务器备份 | 登录使用期间；每日服务器备份 | 离线恢复、数据同步和灾备 | 本机缓存保留在设备；MySQL 备份保留在项目运维控制的存储中，默认 30 天 |

## 必须与代码一致的用户选择

- 昵称、手机号均可选；未绑定手机号不影响基础记录功能。
- 日程订阅消息只在用户保存「未来、带具体时间、一次性」日程并主动同意时创建；拒绝不会阻止保存，也不会反复弹窗。
- 个性化 AI 默认关闭。用户主动开启后才会调用第三方；关闭后立刻停止调用并删除已缓存的 AI 文案。
- 月度报告的金额、预算、趋势和生活统计均在小程序本机根据已同步数据计算；不生成分享海报。
- 随记仅支持正文、发生时间、可选心情和最多 3 个标签；未保存草稿只在本机，不进入同步队列。
- 所有账户、余额、欠款、账单日和还款日均由用户手工填写；不读取金融机构或支付平台的真实数据。
- 用户可在「我的 → 数据与隐私」导出 JSON；也可永久删除账户。删除前要求一次新的微信登录校验，并删除用户资料、同步记录、会话、提醒和 AI 缓存。

## 微信后台逐项核对

1. 按实际能力声明微信登录、微信昵称、手机号、剪贴板与订阅消息；不要声明未使用的图像采集、位置、录音、通讯录或文件能力。
2. 在正式版和体验版都完成隐私指引配置，并用真机验证：未同意时手机号授权会被拦截；同意后才能继续。
3. 在微信后台配置 request 合法域名为 `https://api.你的域名`、socket 合法域名为 `wss://api.你的域名`；不要填写 IP、端口或 HTTP 地址。
4. 订阅消息模板须与服务端字段 `thing1`（事项）和 `time2`（时间）一致，并把真实模板 ID 填入 `WX_REMINDER_TEMPLATE_ID`。
5. 发布前将 `miniprogram/config/runtime.js` 的 `PRODUCTION_API_BASE_URL` 改为正式 HTTPS 域名，并执行 `npm run release:check`。

本文件是工程配置稿，不代替依据实际运营主体、所在地和服务内容完成的法律审阅。
