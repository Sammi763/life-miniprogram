## 用户可见改动

| 范围 | 改动 |
| --- | --- |
| 个人资料 | 可选头像在同账号的设备间同步。服务端将头像放在私有目录，后续可在存储层接入腾讯云 COS |
| 日程与习惯 | 日程支持子任务和单次实例编辑。习惯按生效日期排班，只为当天仍有未完成的计划习惯发提醒。今日页提供提醒中心入口并可继续本机专注 |
| 随记与复盘 | 支持最近删除、往年今日、周复盘记录，以及按今天、近七天或指定日期搜索。打开结果后返回可继续原先的检索 |
| 查账与还款 | 流水可按账户、类型、分类和日期组合筛选，合计覆盖筛选后的全部记录。周期流水按期确认，信用账单可分次还款，结清后停止提醒 |
| 金额精度 | 系统自动按十进制四舍五入到分。明细、账户余额、报表、CSV 和还款提醒一致按整数分计算。同步字段与 v1 备份金额仍以元表示 |
| 同步与退出 | 下载游标使用服务端变更序号，离线队列和被拒写入独立保存。退出副本保留记录快照及本机改动原文，合并预览可单独复制改动 |
| 个性化 AI | 体验版通过服务端开关和用户同意启用，与正式版共用账号和会话。撤回体验同意会清理体验渠道缓存，普通渠道缓存按各自的同意状态保留 |

详细流程见[功能清单](FEATURES.md)。早期需求和性能数据保存在[优化方案](ux-review-2026-10-27/优化方案.md)与[性能基线](perf-baseline-v2.12.md)。

## 部署顺序

1. **准备代码包。** 在仓库根目录从本次提交打包，使用与服务器配置一致的发布号。服务端和 `miniprogram/utils/` 作为同一个发布包交付，继续沿用服务器现有的私有配置、数据目录、存储权限和反代。
2. **备份并迁移数据库。** 保留当前服务端构建、MySQL 备份和头像归档。用现有受控迁移账号在 MySQL 8.0+ 执行 `npm run db:migrate`。迁移补齐记录变更序号、账号序号头和用于回退后重发变更的记录指纹。
3. **验证并启动后端。** 在解包后的 `server/` 执行 `npm ci --omit=dev`，先检查运行模块，再切换服务。使用实际解包目录替换示例路径。检查生产 `/api/health` 返回预期版本。头像默认位于 `DATA_DIR/avatars`，可用 `AVATAR_DIR` 指定服务可读写的私有目录。
4. **上传体验版。** 新服务端健康后再上传构建 `1.0.4`，设为体验版，核对微信后台的 HTTPS request、downloadFile 和 WSS 域名。真机先验证登录、写入和退出重登后读回，再验收头像、离线同步、分次还款和 AI 同意流程。

```bash
# 仓库根目录，请使用本次服务器发布号
RELEASE_VERSION=20261124.1 node server/scripts/pack-release.js

# 本机或服务器的解包目录
release_dir=/path/to/unpacked-release
npm ci --omit=dev --prefix "$release_dir/server"
node "$release_dir/server/scripts/check-runtime-modules.js" "$release_dir/server"
```

旧客户端可继续用旧同步参数。新版客户端会写入新增记录字段与集合，因此与旧服务端配对时可能收到字段校验拒绝。服务端配置检查需要完整源码中的小程序运行配置和法律页，运行包使用模块加载检查。

## 对账、备份与回退

- **历史金额。** 原始记录保留。读旧账时逐笔按新规则换算。可在「我的 → 数据管理」复制备份 JSON 至本地文件，通过 `node server/scripts/audit-money.js <备份文件>` 查看超精度字段、每月收支和各账户余额差额。工具仅输出报告。
- **退出与合并。** 本机 v1 副本中的 `localWrites` 会保留待同步和被拒的原始写入。合并只补缺失记录，遇到同 ID 版本会保留现值。可在预览中复制改动原文，核对后手动补录。
- **头像存储。** 定时任务同时归档 MySQL 和头像目录。头像归档和数据库备份默认保留 30 天。在隔离实例恢复两份备份，再用同一账号检查图片读取。
- **代码回退。** 切回上一稳定服务端包和对应的小程序版本。保留已有数据库结构。再次升级前运行迁移，使旧服务端期间新增或修改的行在原序号之后重新下发。
- **旧数据库恢复。** 恢复后将服务端 `SYNC_GENERATION` 设为该环境从未使用的值，再启动服务。新版客户端会完整补拉并保留待同步和被拒写入。平时发布沿用当前代次。
